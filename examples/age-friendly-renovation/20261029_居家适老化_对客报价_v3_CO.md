# 澄安物业居家适老化市场进入研究报价

完整方案｜v3｜2026年10月29日｜人民币

本次已选完整研究方案，含税总价 **294,383.20元**。研究在杭州、宁波开展，服务期七周，计划2026年11月2日启动、11月27日提交阶段建议、12月11日提交初稿、12月18日提交终稿。团队按研究阶段投入人员。

本项目为模拟测试，澄安物业为虚构委托方，岗位费率、采购单价及税率为模拟参数。工作范围和成果依据同版[研究计划书](20261029_居家适老化_研究计划书_v3_定稿_CO.md)。

## 一、研究范围与交付

研究帮助澄安物业判断是否进入居家适老化改造业务，确定首批家庭、服务组合、合作方式及试点投入。研究包含公开资料、家庭访问、社区问卷、内外部访谈、经营测算与90天试点设计。

| 研究内容 | 约定数量与范围 |
| --- | --- |
| 正式家庭研究 | 20户，两市各10户；其中12户入户、8户线上 |
| 预访谈、替补与补访 | 两市各1户预访谈，另留2户替补额度；最多4户次已访家庭补访核实 |
| 社区问卷 | 160份有效问卷，另做8份预试 |
| 外部访谈 | 8场，覆盖施工改造服务商、社区及养老服务渠道、评估或工程专业人员 |
| 内部访谈 | 4场，访谈澄安物业业务、城市管理、维修和财务人员 |
| 经营研究 | 比较转介服务商与物业签约统筹施工的条件，测算订单、费用、收益及资金需求 |

| 交付材料 | 内容与用途 | 交付日期 |
| --- | --- | --- |
| 阶段建议报告，HTML＋PDF | 汇总阶段材料，比较经营方式，提出试点准备建议及需继续核实的问题 | 2026年11月27日 |
| 完整研究报告，Markdown＋HTML＋PDF | 展开市场条件、家庭需求、服务组合、合作交付、经营情景和试点建议 | 12月11日初稿，12月18日终稿 |
| 可编辑经营测算Excel | 包含输入、公式、假设、来源和三种经营情景，支持调整订单、成本及资金安排 | 随完整报告交付 |
| 试点方案及研究附件 | 90天试点设计、服务商比较、匿名问卷数据与编码说明、家庭主题分析及来源索引 | 随完整报告交付 |

服务包含一次管理层汇报和一轮集中修订。验收核对约定研究范围、有效样本、分析及来源可追溯性、测算公式和文件可用性。

## 五、双方配合与适用条件

澄安物业提供在管小区联系人、已有服务与成本资料，并组织一份集中的修改意见。研究团队负责外部家庭与服务商招募、执行、资料核查和研究交付；具体材料和确认日期见研究计划书“双方配合事项”及“阶段确认节点”。

团队按七周内各阶段的工作投入人员。若需要项目经理、高级研究员和分析员七周全程专属、随时响应，须按专属服务范围另行报价。试点实际施工、销售运营及90天跟踪不包含在本次研究费用中。

本次模拟报价有效期至2026年11月12日，拟开工日为11月2日。若确认日期晚于拟开工日，双方同步调整里程碑；实际开票主体和税费口径在采购确认时核对。新增城市、样本、成果或修订轮次，先核算工作量和人员安排，再由双方书面确认费用与期限。
