# 行业与用户研究框架参考

用于已经完成需求评估、基础情况预研和方法设计的项目。选择能组织本题研究内容的框架，再按实际对象展开；以下是候选方法，不是每个项目必填的栏目。

## 一、行业及企业研究

### 外部环境与发展条件

适用于判断政策、技术或社会变化如何改变行业机会。采用 PEST/PESTLE 的分类，落到具体影响：

- 政策与法律：准入、监管、采购、补贴、责任要求，哪些主体受到什么影响。
- 经济：客户预算、价格、成本、资本投入与融资条件。
- 社会：人口、生活方式、组织工作习惯及需求变化。
- 技术：性能、成本、成熟度、基础设施与替代路线。
- 环境：资源、能耗与环境要求；与课题无关时不单列。

组织成“变化—影响对象—需求或供给变化—经营机会与约束”。例如工业节能设备研究，不能只列政策名称，要展开采购驱动、改造条件、客户节能收益与供应商交付成本。PESTLE适合解释外部条件，市场需求与盈利另设研究板块。

出处：[CIPD：PESTLE](https://www.cipd.org/uk/knowledge/factsheets/pestle-analysis-factsheet/)。

### 行业竞争与盈利结构

五力适用于研究利润为何形成或承压。展开到本行业具体内容：

| 板块 | 可展开的研究内容 |
|---|---|
| 客户议价 | 客户集中度、采购组织、产品差异、转换成本与价格敏感性 |
| 供应商议价 | 关键投入集中度、替代来源、认证与切换难度、供应商向下游延伸 |
| 新进入 | 资本、技术、资质、渠道、客户认证、规模及网络门槛 |
| 替代方式 | 同一需求的其他满足方式、性价比、迁移成本与替代条件 |
| 现有竞争 | 主要群体、竞争维度、差异化、产能、固定成本及退出难度 |

研究不同细分市场或时期的差异，找出对收益影响最大的关系。伙伴与互补产品可作为生态专题补充，不将其称为波特原始五力之一，也不由某一力量强弱直接决定进入或退出。

出处：[HBS：五力](https://www.isc.hbs.edu/strategy/business-strategy/Pages/the-five-forces.aspx)。

### 价值链与企业经营活动

研究行业链条时，沿需求形成、供给生产、交付、渠道和服务，展开参与者、交易关系、价值获取与关键瓶颈。研究具体企业时，使用价值链视角看研发、采购、生产、销售、交付和服务如何共同影响成本与差异化。两种层级分清，不把供应商名单当成企业活动分析。

市场机会项目通常还需需求规模、客户选择、商业可行性和进入条件。用本题的经营问题组织这些板块，不把五力或价值链当成全篇研究。

出处：[HBS：战略与价值链](https://www.isc.hbs.edu/strategy/creating-a-successful-strategy/Pages/default.aspx)。

### 示例：工业设备预测性维护市场进入研究

以下是设计示例，具体范围由前期需求评估确定。

| 研究板块 | 具体研究内容 | 最终呈现 |
|---|---|---|
| 需求与优先场景 | 不同设备的故障损失、停机影响、现有检修方式、付费主体 | 场景分类与需求差异 |
| 技术及实施条件 | 数据取得、传感器改造、误报漏报、模型迁移、现场运维 | 场景适用条件及实施难点 |
| 供给与竞争结构 | 设备厂、自动化商、独立服务商的能力、渠道、客户关系；人工巡检等替代方式 | 竞争群体与进入障碍 |
| 商业可行性 | 客户停机损失改善空间、采购周期、交付成本、持续服务及收入方式 | 客户价值与供应商经营条件 |
| 优先进入方向 | 上述场景需求、实施难度、竞争与收益的并列比较 | 推荐场景、进入条件及后续验证 |

主线是从“哪些场景值得解决”推进到“能否交付、如何经营、优先进入哪里”。桌研、客户访谈和案例分析的安排由前文方法章节负责。

## 二、用户研究

### 需求、选择与转换：JTBD

适用于新需求探索、购买选择、转换及停用研究。围绕具体情境展开：

- 触发情境：何时出现问题、当时有哪些限制。
- 期望进步：功能任务、希望获得或避免的感受、社会关系中的期待。
- 现有办法：竞品、人工处理、组合使用与暂不解决。
- 转换因素：旧办法的困扰、新办法的吸引、对变化的顾虑、原有习惯。
- 购买与持续使用：购买时看重什么，使用中靠什么持续产生价值。

用“情境—任务—现有办法—未满足部分—选择条件”组织需求研究。人口与家庭特征在解释差异时保留，不能用年龄标签代替需求，也不能认定人口特征无用。

出处：[Christensen Institute：JTBD](https://www.christenseninstitute.org/theory/jobs-to-be-done/)。

### 体验过程：用户旅程与服务蓝图

用户旅程适合定位问题发生在哪个阶段。先确定具体人群和情境，再按真实过程划阶段；每阶段展开目标、行动、接触点、困难、感受及结果。产品体验可按准备、首次使用、日常使用、异常处理、维护组织；无需套用认知到忠诚的营销漏斗。

问题涉及服务组织时，再用服务蓝图关联用户行动、可见服务、后台流程与支持资源。例如预约失败，需同时研究用户可用时段、预约界面、排班规则与资源供给。用户旅程展示经历，服务蓝图定位组织如何提供这段经历。

出处：[NN/g：用户旅程](https://www.nngroup.com/articles/journey-mapping-101/)、[服务蓝图](https://www.nngroup.com/articles/service-blueprints-definition/)。

### 行为障碍与持续使用：COM-B

先明确本题要解释的行为，如“新会员每周持续到店”，再展开：

| 条件 | 具体内容 | 健身房可研究的问题 |
|---|---|---|
| 能力 | 身体条件、知识、技能与理解 | 是否会用设备、能否独立训练、身体限制是什么 |
| 机会 | 时间、空间、资源及社会环境 | 路程与作息、可约课程、设备拥挤、家庭或同伴支持 |
| 动机 | 有意识的目标与评价、习惯和情绪反应 | 训练价值感、进展反馈、挫败感、习惯形成 |

将这些内容放入相应的使用阶段，研究它们如何共同促进或阻碍行为。COM-B适合诊断行为条件，不单凭分类就认定因果或证明某项措施有效。

出处：[Michie等，2011：COM-B](https://doi.org/10.1186/1748-5908-6-42)。

### 产品机会整理：机会树

当项目要从用户问题中寻找产品改善机会，可参考“目标—问题/机会—候选办法—验证”的层级。研究框架重点展开问题和机会；若项目尚不包含方案测试，候选办法与验证仅作为最终建议的承接。机会名称写用户遇到的问题，避免把“增加一个按钮”等功能方案直接当作需求。

出处：[Product Talk：机会树](https://www.producttalk.org/2016/08/opportunity-solution-tree/)。

### 示例：健身房新会员留存研究

| 研究板块 | 具体研究内容 | 最终呈现 |
|---|---|---|
| 入会选择与期待 | 触发需求、原有运动方式、选择门店原因、希望取得的进步 | 需求类型与入会期待 |
| 首次体验与融入 | 预约、到店、设备与课程学习、初次训练体验、求助过程 | 首次体验旅程及主要障碍 |
| 持续到店条件 | 技能、作息与路程、课程供给、进展反馈、习惯及社会支持 | 不同使用经历下的促进与阻碍因素 |
| 停用与续费选择 | 减少到店的过程、替代方式、价格与价值感、续费考虑 | 流失路径及可改善环节 |
| 改善优先方向 | 影响人群、问题重要性、门店可控程度及执行代价 | 优先改善事项与效果观察安排 |

比较持续到店、低频与停用者时，沿用方法设计已确定的分组。先定位过程，再解释持续行为，最后形成改善方向；不另重复客户目标、样本计划或费用。
