# 排程与调整方法

## 数量、投入与时间

每项工作写明估算依据：需要处理的数量、每项预计投入、可复用材料、固定准备和协作成本。没有历史效率时使用工作假设，在首批任务后用实际耗时修正。

- 人员投入＝各项数量×单项耗时＋准备、整理和复核时间；多人同时参加同一场访谈，各自投入分别计算。
- 任务历时取决于可用投入、能否拆分并行及外部等待。两人参加一天会议是两个人日，历时仍为一天。
- 样本任务区分邀请、回收和有效样本。有效率用于估算所需回收，响应率用于估算邀请人数；参数随渠道首批结果更新。
- 等待客户回复、数据授权或受访者排期会影响历时，但不能一律计成研究员满额工作量。

例如30场访谈，每场实施1小时、整理1小时、复核0.5小时，共75工时；若两人全程同时参与访谈，再增加30工时。招募协调另算。数量和单位写在一起，便于用户更改假设。

## 从工时排到日历

采用“数量与质量要求→招募及执行条件→完整作业时间→可执行时段→每日容量→人员占用→周期与费用”的顺序。

- **净工时：** 实际准备、实施、整理和复核的劳动量。除以每日标准工时只能得到标准工作量。
- **占用人天：** 按人的日历标记整日、半日或约定时段，说明为何需要占用。预约间隙可用于本项目其他工作时合并，不可利用的碎片说明原因；普通等待答复不自动封锁整日。
- **自然历时：** 从准备到完成的日历跨度，包含招募、预约、节假日、用户休息时间、反馈与前置依赖。

每个任务至少记录：`数量｜净工时｜可执行时段｜每日容量及依据｜招募/等待｜人员占用｜开始—结束｜机动`。当天各任务取时段并集后计占用，不先把每项向上取整再相加。远程晚间访谈可计时段，不能默认收整天；如合同按半日最低单位计费，将商业单位与实际占用分别列明。

### 六类方法的排程落点

| 方法 | 排程处理 |
|---|---|
| 多人座谈会 | 招募与候补先行，同一组在同一时段到齐；主持、记录及场地同步占用，场前布置与组后复盘列入；一个主持不能同时带两组 |
| 拦截问卷 | 按点位和时段估计接触量×合格率×同意率，并与调查员可完成访问量取小值；再按质检有效率估计有效量。各比例须同口径，配额不足按组补，不仅补总数 |
| 入户访谈 | 按路线逐户安排约时，加往返、停车、进出和记录；不能把分散地址当同场地连续访谈，改约后重查路线 |
| 到场体验 | 按培训、任务、复位的完整周期与工位数量排批次，同时核对引导员和对象到场；晚到及设备故障留恢复窗口 |
| 在线访谈 | 先换算时区，再排会话和设备检查、场间记录；等待到约时造成的跨度与实际人员封锁分开，掉线补约单列 |
| 在线问卷 | 编程和预测试通过后投放；各必要配额分别估算有效回收速度，最慢一组决定收口时间，再加质检与补样；不将平台全天开放视为团队全天工作 |

数量÷每日容量只得到候选执行日数，还须映射到实际可用日期。周末活动按周末数量排；夜间工作与次日休息、跨城交通及调休核对人员容量。缺少效率数据时列区间，首批校准；预访谈、补访与机动分别说明数量和启用条件，避免重复预留。

排程交给报价时，按人、按周补充任务以外仍被本项目锁定的时段、原因，以及剩余时间能否安排其他收费工作。例如连续驻场或承诺随时响应可能占住额外容量；普通等待、公司本来没有其他订单的空档不直接归给本项目。未确定的容量保留为报价情景，字段和成本处理统一使用[计价与变更方法](计价与变更方法.md)；日历仍显示真实任务与预留，不把额外锁定伪装成已安排的研究工作。

## 排程顺序

1. 列出交付日期、人员可用时间、假期及需要客户或供应商提供的输入。
2. 为工作包指定前置任务。可以重叠的工作使用明确批次，例如“首批6场访谈已整理后开始问卷修订”；不能用“同时开展”掩盖未到位输入。
3. 根据前置完成时间和资源安排开始、结束时间。对同一人的日/周总投入求和；超过容量时重新安排，再检查下游日期。
4. 标明最可能推迟最终交付的任务链、关键外部输入及缓冲。缓冲写明预留给什么情况和由谁决定使用，不默认固定比例。
5. 用一次延迟或短缺情景检查方案：哪些任务还能继续、补救需要多少投入、何时必须决定、最终期限是否改变。

复杂项目可计算关键路径；小项目只需清楚标出影响交付日的依赖链，避免伪精确的日期和甘特图。

## 质量验收的执行方式

| 对象 | 执行安排应说明 |
|---|---|
| 公开资料 | 来源与原文、时间与口径、重复和矛盾怎样核对；哪些资料可进入分析，哪些待补 |
| 问卷 | 入组和配额、逻辑与重复、无效答卷处置、有效样本和关键分组、变量版本；预试修改后的答卷是否可合并 |
| 访谈 | 对象匹配、授权范围、录音/记录完整性、关键问题覆盖及转写核对；哪些内容可用于比较与引用 |
| 分析成果 | 数字复算、主张与证据对应、跨方法冲突处理、模型假设和版本 |
| 最终文件 | 核心问题覆盖、正文与表格一致、引用和附件可用、约定格式实际打开检查 |

检查后的交接保留可使用版本及尚待解决的问题。返工只针对受影响部分，已经合格的材料可继续加工。

## 延迟与变更

记录“发生了什么—影响哪些任务和成果—剩余工作量—可选处理—推荐方案—谁何时决定”。

例如原计划按80%有效率取得300份有效问卷，预计回收375份；前批100份仅70份有效，剩余230份若按70%估算，需再回收约329份。先查低有效率原因，再核对费用、渠道和质量处理人力，重新估计完成时间；不要仅把总回收量提高后保留原来的资源和期限。

调整后保留原计划与新版本的差异，更新后续任务、成本驱动项和交付内容。状态用未开始、进行中、待输入、待验收、已完成等直白名称，附实际产出或阻碍，不以主观完成百分比替代进度证据。
