# 研究问题与方法设计

## 从决定倒推研究

例如“研究三个教育硬件赛道”，先确定是选择投资尽调方向、决定新品进入，还是改进现有产品。投资筛选需要需求质量、竞争与经济性；产品改进更重使用任务、失败场景和购买阻力。同样的行业对象，研究问题、受访者和分析方式会不同。

把宽问题拆成能够改变选择的子问题，保留其联系。区分已有事实、需要检验的解释及开放探索；假设用于组织求证，也应给相反结果留出分析位置。

## 需求评估与推荐范围

先把口述委托转成公司层面的研究目的：公司已有业务与能力、希望实现的发展目标、正在考虑的新行动，以及研究需要支持的具体决定。背景介绍后必须写出研究目标，不能以“支持整体经营决策”代替决定的内容。尚属研究者推断的战略意图先标为待确认，不补造客户目标。

私下沟通中的部门立场、情绪和对个人的评价用于理解委托及安排独立求证。对客方案将其转为需要检验的产品、市场、流程或资源问题，不把某部门的指控写成公司事实。与研究有关的已发生测试、投诉等事实保留具体对象、场景和来源状态；中立表达不等于掩盖问题。组织矛盾本身属于明确委托范围时，按约定对象和读者处理。

先解释客户希望改变什么业务结果、正在面对哪些选择，再逐项拆成研究能解决的问题。先写“客户需求理解”：用客户的经营或管理语言说明当前处境、希望改善的结果、面临的选择，以及为什么需要这项研究；未获得确认的背景写为待确认理解，不把研究假设当成客户已发生的问题。按本项目实际诉求划分需求板块，每块写清核心商业问题、具体子问题和客户将据此作出的决定，再评估研究深度，板块数量不固定。

对每块明确本轮能深入回答什么、能提供怎样的咨询建议及交付物。需求评估说明关键条件如何影响回答深度；具体资料内容、时间范围、提供责任人和取得时点列入项目协作或执行安排。客户需求章按委托方背景与目标、具体需求、研究价值与回答深度递进，不夹入报价或资料索取清单。技术条件翻译成业务描述，例如“购买和到店记录能够对应到同一会员，且每位纳入分析的会员都有开卡后90天记录”，不只写“主键可关联、观察窗完整”。

每项需求评估四件事：

- **价值：** 回答后会改变哪项行动；属于必答问题还是有价值的延伸。
- **难度与原因：** 难在概念测量、数据质量、对象接触、比较条件还是观察周期；按实际障碍排列先后。
- **可回答程度：** 现有资源下可完整回答的范围、只能部分回答的部分，以及本轮不能回答的内容。结合证据覆盖解释，说明扩大覆盖、增加方法或延长周期可以补上什么。
- **推荐取舍：** 优先解决什么、舍弃或后置什么、保留哪项验证；把资源投入能最大程度改变决策的不确定性。

例如“提高续约率”可拆为流失在哪里、客户为何离开、企业能改变什么、先改哪项、改善是否有效。合同和工单可分析流失分布；访谈与事件对照可解释流失机制；行动成本和服务资源帮助排优先级；改善效果需要实施后的观察或对照。研究计划据此交付可执行的改善选择及验证设计，而非承诺在诊断期证明续约提升。

## 研究思路：从客户决定组织研究

研究思路说明研究者准备怎样解决客户的具体问题。先写清委托方希望改变的经营或管理状况、拟采取的行动及尚不确定的条件，再解释各项研究为什么需要做、采用哪些方法、结果如何共同支持决定。方法在这里交代选择理由及作用，样本、工具、场次和实施细节在方法详述中展开。

按本项目组织连续论述，每个研究模块讲清四件事：**要解决的具体问题、选择的研究办法及理由、预计形成的回答、该回答怎样影响客户的选择或后续研究。** 模块之间说明实质联系；可并行开展的研究，在综合判断时怎样结合也要写清。模块数量由问题决定，不固定四步流程。

例如企业拟将新教育硬件推向家庭零售市场，可以这样组织：

1. **行业发展与需求空间。** 研究购买家庭、销量、价格、换机和细分人群的变化，判断增长的来源及条件，识别企业可争取的需求。市场销售额增长不直接等于购买人数增长，也不直接等于该企业能够获得份额。
2. **竞争企业的经营投入。** 结合企业资料及渠道、相关从业者访谈，研究产品内容、品牌推广、获客、渠道和售后的投入与经营结果，判断委托方需要哪些资源及能否承担。
3. **目标家庭与产品接受度。** 通过购买者访谈、使用者观察、产品比较或问卷，研究家庭的选择理由及实际使用，明确具体客群、产品改进和购买条件。
4. **进入方案与投入回报。** 将可争取的需求、产品表现和企业资源结合，比较进入方式、资金需求与经营回报，提出是否进入、如何进入及下一步验证安排。若研究支持探索学校市场，另列学校需求、采购和实施条件的后续研究，家庭研究不能直接替代学校研究。

以上是推理示例，不是所有项目的必选模块。用户研究、经营诊断和其他课题按各自决定选择方法。市场进入课题应检查行业空间、竞争经营、购买使用、企业能力与回报是否有实质遗漏；已有可靠结论可以复用，不能因已有样机或客户只谈产品体验而跳过决定进入价值的重要问题。

分页时先说明整体设计，再按需要展开关键模块和模块关系。主标题使用具体研究对象与角度，副标题解释本页方法为何能解决客户问题。汇报日期属于周期安排；拟报告目录属于研究框架；这些内容不替代研究思路。概念和比较关系服务具体研究，不把“用户证据到经营判断”等内部概括直接当客户页面标题。

## 主要方法怎样写到可执行

每种主要方法用独立小节说明设计理由和做法，不以“桌研＋访谈＋问卷”替代方案。

| 设计内容 | 应写清什么 |
|---|---|
| 对应问题与适用性 | 解决哪个问题，为什么选它，与其他方法怎样互补 |
| 研究对象与覆盖 | 总体、分析单元、入选排除、样本来源、关键分组、数量依据和替补 |
| 采集与测量 | 收集哪些字段、主题或行为；关键概念如何定义，时期、分母和比较条件是什么 |
| 实施与处理 | 招募/取数、预试、记录、清洗、编码或指标计算的具体步骤 |
| 分析与判断 | 比较哪些对象、怎样解释差异、用哪些结果支持或改变判断；模型须具备相应数据条件 |
| 质量与衔接 | 核对什么、谁复核，缺项如何处理；交给后续分析什么成果 |

写出本课题的关键分析表或编码字段示意，帮助读者看见从材料到判断的加工过程。方法介绍与资源核算使用同一数量；完整工具题目在方案确定后制作。

## 选择方法，同时设计分析

| 问题需要什么判断 | 可用方法 | 如何形成判断 | 设计时要落实 |
|---|---|---|---|
| 现状、规模、结构及变化 | 桌研、统计或经营数据整理、案例比较 | 统一口径后拆分、对比、趋势或情景测算 | 年份、地域、总体、单位、分母；来源覆盖和代理指标依据 |
| 行为、需求、动机及过程 | 深访、观察、任务体验、公开案例编码 | 按角色与情境比较，解释行为链、障碍与替代办法 | 招募标准、不同经验与反例、记录和编码方法 |
| 需求或行为分布、群体差异 | 问卷、现有样本或日志分析 | 描述分布、交叉比较，按问题做关系或分群分析 | 总体与样本框、招募渠道、关键分组、测量指标及样本依据 |
| 干预、产品或方案是否造成改变 | 随机实验；条件合适的准实验 | 预先确定主要结果与比较方式，估计差异及不确定性 | 对照条件、分配机制、基线、混杂因素、流失及所需样本 |
| 商业可行性、投入回报和机会优先级 | 案例、客户/渠道访谈、经营数据及情景模型 | 连接需求、转化、收入成本、约束与敏感参数 | 参数取得途径、可比性、决策标准及关键假设 |

方法按问题组合。只有访谈时，可以解释机制与形成假设；需要比较比例时加入适当定量设计。只能观察相关关系的材料，成果定位为关联与解释线索；若用户需要因果判断，明确追加的比较设计。

## 样本与案例规模如何确定

- **定性研究：** 从角色、使用阶段、场景和差异经验决定覆盖；说明初始案例分配，边分析边补充尚未解释的类型或反例。是否扩样依据问题是否得到解释，而非套用固定人数。
- **定量研究：** 先确定主要指标和最小分析分组，再说明规模依据。估计精度或统计功效需要预期比例/变异、允许误差或最小差异、置信水平及抽样设计；参数未知时用合理情景计算并列明假设。
- **便利或配额样本：** 说明渠道和配额为何有助于覆盖目标差异，按实际样本支持比较；全国总体比例需要额外的抽样或校准依据。
- **稀缺对象：** 先核实可接触数量和资料深度，优先用多来源案例及关键角色互证；记录哪些问题仍需直接接触对象。
- **多方法：** 分清独立样本与同一人重复参与，说明衔接顺序。例如访谈提炼选项，问卷比较分布，回访解释异常群体。

## 从材料到决策的例子

问题：“低价设备是否只是一次性尝鲜？”可先比较持续使用者与停用者的任务、替代产品和停止原因，形成使用机制；再用问卷比较使用频次、购买时间和停用比例，结合渠道退货与复购资料。成果是持续使用条件、主要流失原因及值得进一步验证的人群，而不是把几句好评汇总成“需求旺盛”。

若任务是六周内决定优先尽调哪条赛道，行业全面普查可能不如三个赛道同口径比较有效。先查可得市场与企业资料，访谈识别关键经营变量，再用有限用户研究检验最影响排序的需求假设。样本、费用和期限都围绕这一判断配置。

## 资源与可行性

将工作量拆为资料处理、招募、采集、质检、分析和交付修改。核对可用人员的有效工作日、受访者排期、数据授权及采购周期。对于最可能改变成本或期限的条件，指定核实时间与替代做法；备用方案说明它会少回答什么，避免只写“视情况调整”。

### 一线调研的周期与预留

人日表示实际劳动量，项目周期还包含招募启动、筛选与预约、受访者等待、场地协调和反馈周转。先列依赖和可接触窗口，再安排每人的工作；招募可与资料分析并行，正式采集需承接预试及工具修订。

- **招募：** 说明渠道准备时间、筛选与预约责任、目标完成数及候补安排。根据渠道经验估算触达、合格和到场的转化；未知时先小批招募验证，按结果修订完成时间。
- **预访谈与预试：** 在正式执行前安排少量对象、复盘和工具修改。仅当对象合格、核心内容覆盖且版本可比时计入正式样本；预算先考虑不能计入的情形。
- **正式采集：** 分批安排，场次之间留整理、质量复核和调整时间；纳入周末、交通、场地和对象可约时间，预留改约与爽约替补窗口。
- **补访：** 为未解释的差异、反例或关键缺口预留对象、工时和酬谢；注明是回访同一人还是新增对象，不能重复累计独立样本。
- **机动与交付：** 将现场机动和分析、客户反馈分开安排，说明何时启用、谁能投入及对交付日的影响。等待时间不自动等于新增人日，实际追加的协调、采集和修改则计入费用。

计划列基准周期、可用机动窗口及仍需确认的条件。客户期限紧于可行周期时，提出缩小范围、增加并行人员或分阶段交付的具体取舍。周期延长或新增预试、补访后，重新核对人员容量、酬谢、差旅及服务报价，不能沿用旧总额直接宣称预算够用。

### 不同方法的执行日历

选用某种方法时，先了解目标对象的实际作息。普通消费者可能仅周末白天或工作日晚间方便，企业对象则可能受工作班次和业务高峰影响，不能将其中一种作息套给所有人。把招募准备、预约窗口、现场执行、整理和反馈分别排入日期；一组只能周六开展的活动，即使净工时很少，也可能跨数周。

| 方法 | 设计周期时应核实 | 每日容量依据 |
|---|---|---|
| 多人线下座谈会 | 同组配额对象同时可到场、招募与候补、主持/记录人员和场地档期、晚间或周末、组间复盘 | 场次完整时长与场地周转；组员数量不是可逐人独立预约的场次数 |
| 线下拦截问卷 | 点位许可、时段覆盖、人流、筛选通过与同意率、天气、调查员和设备 | 可接触合格人流与人员访问能力两者中的较低值，再考虑无效样本及配额 |
| 入户访谈 | 地址分布、家庭预约、进出准备、交通停车、家庭成员作息、取消改约 | 按实际路线累加路程、访问、转场与记录时间，逐户检查约时能否衔接 |
| 邀请用户到场体验 | 招募、到场窗口、设备/工位、培训体验、设备复位、候补 | 用户、工作人员和设备中最紧的容量；不同批次留周转及异常处理 |
| 在线访谈 | 时区、作息、预约提醒、设备预检、主持与记录安排、掉线改约 | 可约会话及场间处理窗口；无路程仍可能跨多个晚上 |
| 在线问卷 | 样本来源、编程测试、预测试、分批投放、各配额发生率与回收速度、质检补样 | 最慢必要配额的有效回收速度；平台并发量不等于有效样本产能 |

记录容量的来源或工作假设；未知时先做小批招募/试执行，再更新方案。方案至少显示：任务、数量、净工时、可执行时段、每日容量及依据、招募与等待、人员占用、预计起止和机动。主报告可用阶段摘要，详细日历按项目复杂度附后。时间约束使某方法无法支持决策时，比较减少覆盖、改方式或延长周期的代价。

## 方法参考

- [MRS：购买研究与洞察指南](https://www.mrs.org.uk/pdf/Best-Practice-Guide-to-Buying-Research-and-Insight.pdf)：从委托目的、研究设计和使用价值评价方案。
- [GOV.UK：规划用户研究](https://www.gov.uk/service-manual/user-research/plan-user-research-for-your-service)：研究问题、人群、方法与阶段安排相联系。
- [HM Treasury：Magenta Book](https://www.gov.uk/government/publications/the-magenta-book/magenta-book-central-government-guidance-on-evaluation-html)：使问题、设计、数据和资源相匹配，按判断任务选择评价方法。
- [DARPA：Heilmeier问题](https://www.darpa.mil/about/heilmeier-catechism)：说明目标、价值、方法依据、资源和阶段成功标准。
