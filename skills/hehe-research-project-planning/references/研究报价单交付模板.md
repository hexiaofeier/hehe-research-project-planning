# 研究报价单交付模板

## 一、交付载体

默认交付一份 Markdown 对客报价草稿。形成或复核价格时保留内部测算，与对客稿分开；仅排版已有确认价格时沿用原依据。未确认条件明确列为待定；用户要求的模拟报价显著注明测试假设。

## 二、Markdown 主报告

1. **报价摘要：** 项目、版本、币种、总价或已知小计、税费口径、交付周期和报价状态。
2. **工作范围与交付：** 研究对象、地域、数量、方法、成果、验收及包含的修改轮次；对应计划书或执行方案版本。
3. **费用明细：** 工作包、产出、工期、计价单位、数量、单价、金额、包含服务与单价依据；列出折扣、税额及应付汇总。
4. **付款与双方配合：** 节点、金额和支付条件，客户材料/招募责任、第三方采购与结算方式。
5. **有效期、假设与变更：** 需要确认的条件、范围外工作和可选项、原价适用边界、数量/地域/成果/修改轮次变化的处理。

表格示例字段：`工作包｜工作与产出｜工期｜单位｜数量｜单价｜金额｜计价依据与包含项`。相关重复信息可以集中写一次并引用。

## 三、其他交付物

| 触发条件 | 交付物与最低内容 |
|---|---|
| 用户需要调整参数、比较方案，或报价存在多种复杂计算 | Excel计算表：范围与单价输入、逐行公式、费用汇总、税费、付款、变更差额；输入和公式可区分，正文与表格一致 |
| 形成或复核价格 | 内部测算附件：逐人逐周的任务、额外锁定、可另用及待确认容量；薪酬与年度可计费产能、公共费用分摊、硬成本、执行预留及参数依据；完整成本保本价、目标利润报价、拟成交价对应利润和不利情景；对客明细勾稽、预算差额与范围选项，新旧报价差额解释。沿用[计价与变更方法](计价与变更方法.md)的字段和算法；简单项目用Markdown即可 |
| 客户要求正式可编辑或固定版文稿 | Word或PDF：同版报价与条款，检查表格、分页和总额 |

对客文件展示服务销售单价及计价数量，内部工资、成本费率与利润不默认附送。报价在计划书中独立成页，移除报价不影响研究方案和交付清单。附件不因格式齐全而生成；外发另按用户授权执行。

## 四、保存与命名

沿用用户目录和命名规范；已有项目放入计划/商务目录，否则在当前工作目录建立项目报价目录。默认 `YYYYMMDD_研究主题_研究报价单_v1.md`；内部测算在文件名加“内部”，变更稿用新版本并说明变更。交付列出实际路径，不覆盖原报价。

## 五、信息缺口

集中列出影响价格的范围、费率、采购、税费、付款和时效待定项及提供方。企业成本或费率待核时，以明确参数假设和情景形成报价讨论稿；范围、数量也不足以估算的部分才保留待填，并说明补齐后怎样计算。数值已齐但商业条件未确认时仍标为讨论稿。

## 六、交付条件与检查

- 工作包、样本单位、工时和成果与约定范围相符；人工计费单位与日历占用对应，同日任务不重复取整，路程及现场费用有依据。
- 费率或反推总额有依据；成本、预留、利润与税费分别核对，公共费用未重复计入；缺项不按零处理。
- 全服务期人员容量能够核对；额外锁定有具体原因，待确认容量已做情景，年产能分摊与项目空档没有重复计算；拟成交价及不利情景的利润均已列出。
- 从总额反编的对客明细与真实工作量一致，合计勾稽；没有为了满足目标价虚增人日或硬成本。
- 金额、折扣、税费及付款复算一致；涉及多币种时列明汇率及日期依据。
- 外采、客户配合及修改轮次可执行，变更算法与原定价条款一致。
- 对客稿和内部测算分开；已确认条件与建议条款可识别。
